# GRAVITYVAN · 중력의 성채

중세 판타지 분위기의 중력 전환 퍼즐 액션 게임. 설치와 외부 라이브러리 없이 `index.html` 하나로 실행됩니다.

## 플레이
- 방향키 / WASD / 화면의 네 방향 버튼: 중력 방향 선택
- Space / 중력 전환 버튼: 아래 → 왼쪽 → 위 → 오른쪽 순환
- R: 현재 층 다시 시작, Esc: 일시정지
- 황금 열쇠를 모두 모은 뒤 빛나는 문에 닿으면 다음 층으로 이동합니다.
- 붉은 저주의 문양에 닿으면 재도전합니다. 공중에서도 중력을 바꿀 수 있습니다.
- 8개 층, 경로 힌트, 효과음 선택, 진행 및 최소 전환 횟수의 브라우저 자동 저장을 지원합니다.
- 방향 전환은 다음 타일 중심에서 반영됩니다. 힌트는 벽에 멈출 때마다 입력하는 방향 순서입니다.

## GitHub Pages
저장소 Settings → Pages → Build and deployment에서 **Deploy from a branch**, **main**, **/ (root)** 를 선택하고 Save를 누릅니다.
배포가 완료되면 https://cloverkimhughie.github.io/gravityvan/ 에서 플레이할 수 있습니다.

## 검증
`node test.cjs`로 실제 게임 업데이트 함수를 실행하여 8개 층의 해답, 위험 구역, 재시작, 일시정지, 진행 저장을 검사합니다.
